# Network Port Scanner GUI

## 📌 Project Description
This project is a Network Port Scanner with a graphical user interface built using Python. It scans a range of ports on a target system and displays open ports along with their services.

## 🚀 Features
- Simple GUI interface
- Multi-threaded fast scanning
- Displays open ports with service names
- Real-time scanning progress

## 🛠️ Technologies Used
- Python
- Tkinter
- Socket Programming
- Multi-threading

## ▶️ How to Run
1. Install Python
2. Download the project files
3. Run the command:
   python portscanergui.py

## 📊 Output
The tool scans the target and shows open ports such as:
- Port 22 (SSH)
- Port 80 (HTTP)
